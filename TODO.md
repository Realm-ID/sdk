- [x] **`go/auth.go` — `SessionInfo.LastUsedAt` json tag mismatches the server** (DONE 2026-07-08). Fixed the drift in all three SDKs: Go json tag + `decodeSessionPage` key → `last_seen_at`; Java `Session` `@JsonProperty("last_seen_at")`; TS `SessionInfo` realigned to the untransformed wire shape (`created_at`/`last_seen_at` numbers). - [x] **`go/origins.go` — `Origin.DetachedAt` is never populated by the issuer** (found 2026-06-30; RESOLVED 2026-07-09, `go/v0.26.0`). See `CHANGELOG.md` (go/v0.26.0) + `DECISIONS.md` (2026-07-09).

Add the on-behalf-of header path to the TS HttpClient + these methods for cross-language parity.
- [x] **Long-lived-client token manager** (SHIPPED 2026-05-28, SPEC §4.2.1) — `NewTokenManager`/`newTokenManager` + `RefreshSink` (persist-before-return) + single-flight live in `go/token_manager.go` and `ts/src/token-manager.ts`.
